NEXUS Lab / Research

Research

We study secure and trustworthy software through interconnected research in software security, AI-assisted software engineering, software analysis, and empirical studies.

Integrated themes

How the areas fit together

THEME 01

Software Security & Privacy

We investigate software security and privacy risks at code, architecture, application, and ecosystem levels. Current interests include malware and vulnerability analysis, Android and mobile security, privacy risks, secure code analysis, and software assurance.

Software Security & Privacy Malware & Vulnerability Analysis Mobile & Android Security
THEME 02

AI, Trust & Assurance

We study AI as both a software-engineering capability and a source of new assurance challenges. This includes trustworthy AI, LLMs and coding agents, security analysis with AI, evidence-grounded reasoning, validation, and false assurance.

Trustworthy AI AI-Assisted Software Engineering
THEME 03

Software Analysis & Empirical Studies

We use empirical methods and software analysis to understand software properties at scale, including metrics, quality, maintainability, architecture, software analytics, datasets, and reproducible evaluation.

Software Analysis & Analytics Software Quality & Metrics Empirical Software Engineering

Research areas

Eight connected areas of investigation

These areas provide the detailed research directions underlying the three integrated themes above.

Software Security & Privacy

Secure software design, privacy risks, data protection, security testing, and evidence-based assurance.

Malware & Vulnerability Analysis

Malware detection and characterization, vulnerability analysis, weakness discovery, and security-focused program analysis.

Mobile & Android Security

Security and privacy of Android and mobile ecosystems, including inter-app communication, repackaging, and wearable companion apps.

Trustworthy AI

Reliability, security, evidence grounding, and responsible evaluation of AI used in software and security tasks.

AI-Assisted Software Engineering

LLMs and coding agents for generation, testing, debugging, analysis, and secure software development workflows.

Software Analysis & Analytics

Static and empirical analysis of software artifacts, repositories, behaviors, and large-scale software datasets.

Software Quality & Metrics

Software metrics, maintainability, code smells, architectural quality, and security-aware quality assessment.

Empirical Software Engineering

Evidence-driven studies of software systems, developers, tools, datasets, and engineering practices.
